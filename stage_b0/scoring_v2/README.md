# B0探索性评分收集v2

此目录是既定B0协议的工程执行适配，不是新防御。与v1的行为差异仅为：明确使用用户授权且已完成的探索性AI标签门；补齐既有DataSentinel、B4/B5收集路径；逐条保留异常与观测，且PG2因003固定版本403缺失。原run_classifiers.py、人工门、历史数据与旧结果不改。

当前候选无任何本轮评分，GPU收集入口未在协调端运行。`run_all.py --check-only`只核字节、源分组和标签覆盖，不证明GPU前向或检测性能。真实GPU代码路径必须由B0-5090-004实际执行并验收。

执行任务见`coordination/tasks/B0-5090-004.md`。冻结执行配置为execution_plan.json，绑定源文件、原协议、提示、实际003回执、标签门、模型资料及新收集代码的SHA256。禁止运行中编辑。freeze_plan.py是协调端一次性配置构建工具，执行端不得重建配置规避摘要失败。

分类器沿用已审固定文件；如5090缺文件，首次允许下载固定PG1/PIGuard到E盘，禁止把本机CPU速度拿来比较GPU延迟。DataSentinel/Llama离线复用现有快照。PIGuard自定义模块在执行前逐文件核摘要，其他开发脚本不执行。

每角色独立进程，监督进程带独占锁，新建唯一raw/回执目录，只写追加文件。401/403单列缺失可接续独立模型，其余失败保留并停止。无样本重试、JSON修复、提示优化或阈值调整。

所有本轮输出是探索性AI标签评估，不是人工金标或确认性研究。没有运行目标业务，不能把检测阳性/阴性改称因果ASR。统计与阈值冻结在后续独立步骤，不在本次收集自动开始。

准备阶段的首份配置保存在`preparation_attempts/execution_plan-2f2f8800.json`。它只做过本机check-only，随后补充了运行时版本记录的真实性检查，未加载模型/评分；保留该准备快照，不作为可执行任务配置。当前execution_plan.json为唯一派发配置。
